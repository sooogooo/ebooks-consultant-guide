# 美丽心灵 - 医美咨询师的应用心理学宝典
## Beautiful Mind - Applied Psychology Treasure Book for Medical Aesthetics Consultants

---

## 📖 项目概览

本项目是一套完整的中国医美咨询师应用心理学指南，整合了科学心理学、积极心理学、消费心理学、社交心理学、医疗叙事学等多个领域的理论与实践方法。

**项目特色：**
- **系统性**：涵盖从理论基础到实践应用的完整知识体系
- **本土化**：紧密结合中国医美市场特点和文化背景
- **实用性**：提供可操作的评估工具和干预技术
- **前瞻性**：关注数字化时代的远程咨询技术
