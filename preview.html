电子书本地预览工具

选择以下任一方式预览电子书：

方式一：浏览器直接预览

  1. 点击下方按钮，选择电子书目录中的index.html文件
  2. 浏览器将在新标签页中打开电子书
  3. 请注意：由于浏览器安全限制，某些功能（如本地资源加载）可能无法正常工作

方式二：使用本地服务器（推荐）

使用本地服务器可以获得更好的预览体验，避免浏览器安全限制问题。

使用Python：

1. 确保已安装Python（推荐Python 3.6+）

2. 打开命令提示符，导航到电子书所在目录

cd /d e:\WorkDirs\ebook\consultant

3. 运行以下命令启动服务器：

python -m http.server 8000

4. 在浏览器中访问：http://localhost:8000

使用Node.js：

1. 确保已安装Node.js和npm

2. 安装http-server包：

npm install -g http-server

3. 打开命令提示符，导航到电子书所在目录

cd /d e:\WorkDirs\ebook\consultant

4. 运行以下命令启动服务器：

http-server -p 8000

5. 在浏览器中访问：http://localhost:8000

提示：如果您的浏览器阻止了弹出窗口，请允许此网站的弹出窗口。
